## 四、技术栈差异说明（答辩核心，请重点准备）

任务书 5.1 指定技术栈，实训过程中经**实测环境能力**后采用等价的 CloudBase 落地形态。差异及成因如下：

### 1. 「文档数据库（MongoDB）」→ CloudBase PostgreSQL（关系型）

- **任务书表述**：采用文档型云数据库，规划 6 个集合。
- **实测事实**：本次实训使用的 CloudBase 环境（体验版，EnvId `aaa-d8gj21kc1d09d6414`）经平台接口核查 **未开通文档数据库实例**，平台唯一可用的数据库为 **PostgreSQL**（实例 `pgdb-nzmp7hzz`），关系表承载了任务书规划的全部 6 类数据对象。
- **等价性说明**：6 个"集合"一一映射为 6 张关系表（见 §五），字段、关联与业务规则完全一致；对外接口契约（前端零感知）不区分底层是文档还是关系库。**数据模型等价，仅是存储引擎不同。**
- **答辩话术**：*"任务书要求文档型云数据库，但实训账号所属 CloudBase 环境未开通文档库实例，PostgreSQL 是该环境唯一可开通的数据库。为保障双端功能完整落地，我按 1:1 关系建模复刻了任务书的全部数据对象，接口层对前端完全透明。"*

### 2. 「云函数」→ CloudBase HTTP 云函数（保留，形态升级）

- 后端采用 **Express 整体打包为 HTTP 云函数 `meiyu-api`**（Node.js 18，自包含部署包，`scf_bootstrap` 监听 9000，网关路由 `/api` 全路径透传）。
- **与任务书一致**：任务书要求的"云函数"形态完整保留；比单事件函数更适合 REST 服务，业务代码零改写、30+ 接口全部运行在云函数内，无独立服务器。

### 3. 「云存储（对象存储/COS）」→ CloudBase pgstore 公共桶

- **任务书表述**：作品图片存云存储，返回可访问 URL。
- **实测事实**：PG 模式环境的对象存储为 **pgstore**（与旧 COS 是两套系统，旧 COS API 不可用）；作品桶 `art-works`（public=true，单图 ≤5MB，image/jpeg|png|gif|webp|bmp 白名单），匿名读取经 RLS 策略放行。
- **落地**：上传接口 `POST /api/work/upload` 鉴权后用 service_role key 直传 pgstore，返回公网可匿名访问 URL 回填作品 `images` 字段；本地开发未配置存储密钥时自动回退 `uploads/` 目录。
- **答辩话术**：*"平台存储为 pgstore 对象存储，功能语义与 COS 一致（桶/对象/公开读 URL），我用 HTTP API 完成了上传与公网直读，图片不落函数实例盘，重启不丢失。"*

### 4. 「云托管（Docker）」→ HTTP 云函数替代

- **实测事实**：实训环境**未开通云托管（CloudRun）**。
- **等价性**：任务书用云托管是为部署常驻 HTTP 服务；HTTP 云函数提供相同能力（公网域名、REST 路由、弹性伸缩），且同为任务书认可的"云函数"技术栈，故以 HTTP 云函数承载后端服务，不引入 Docker 构建链路。

## 六、双端协同闭环验证记录（真实落库）

1. **体验期登录真实化**：`WECHAT_APPID` 未配置时 `/api/user/login` 走演示模式，签发正式 JWT 且身份为真实 DB 用户（默认林小满）——避免发布操作降级到本地假数据。
2. **发布 → 审核闭环实测**（公网）：
   `POST /api/user/login`(演示登录 200) → `POST /api/work/create`(workId=128, pending) → 管理端 `POST /api/admin/work/approve`(200) → 作者 `GET /api/work/mine` 状态回传 **approved** ✅
3. **Web 管理端浏览器级 E2E**：登录 → 审核列表 → 通过/驳回（必填原因）→ 状态与原因正确展示（截图存档于会话记录）。
4. 反向闭环：驳回 → `rejectReason` 回传小程序「我的」页红条展示。

## 七、演示指引与注意点

- **演示路径**：小程序发布作品（自动 pending）→ Web 管理端「作品审核」通过 → 小程序「我的」出现"已通过"→ 沐光墙可见。全程真实数据。
- **测试域名风险提示**：Web 管理端使用腾讯云测试域名，浏览器可能先出现"该网站的安全证书/风险提醒"页，需点"继续访问/确定"进入（答辩前建议先预演一次）。
- **正式上线前置**（仅 1 项必办）：向微信公众平台申请小程序 AppID/Secret，填入云函数环境变量 `WECHAT_APPID/WECHAT_SECRET` 后重新部署——演示登录分支自动失效，小程序切换为真实微信登录；同一环境配置合法 request 域名后即可真机发布。
